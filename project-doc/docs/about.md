# About

Autonomous Recruitment Agent is a recruitment automation platform built with:

- FastAPI for backend APIs
- React + Vite for frontend dashboard
- PostgreSQL for persistent data
- n8n for workflow orchestration

## Purpose

Reduce manual hiring effort by automating screening, interview coordination,
feedback lifecycle management, and onboarding handoff.

## Ownership model

- Public repository: application code and deployment assets
- Private repository: proprietary workflow definitions and operational playbooks

## Contribution direction

When adding new modules or endpoints:

1. Update this MkDocs set in project-doc/docs
2. Keep workflow implementation details in private documentation
3. Preserve separation between public architecture and private automation logic
