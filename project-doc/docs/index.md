## What this project is

This is an AI-assisted HR automation platform with:

- Resume ingestion and parsing
- AI-based resume-to-job matching
- Role-based authentication and portals
- Online assessment (OA) lifecycle and score capture
- Interview scheduling and reminders
- Feedback collection and decision flow
- Onboarding initiation
- n8n workflow integration
